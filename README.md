# KitCat

KitCat is a simple and powerful Node.js CLI tool designed for developers who want to provide context to an AI about their project. By recursively walking through your project directory, KitCat generates a comprehensive tree view of your files, and outputs the contents of text files or metadata about binary files into a single `output.txt` file.

## Why Use KitCat?

When working with AI systems that require understanding your project structure and file contents, KitCat makes it easy to give them all the context they need in one convenient file. Whether it's for documentation, analysis, or simply sharing context with AI, KitCat helps you capture the full scope of your project.

## Features

- Recursively scans your project directory.
- Outputs a clean and organized directory tree structure.
- Displays the content of all text files.
- For binary files, it outputs key metadata (size, creation date, modification date).
- Saves everything to a single `output.txt` file for easy sharing.

## Installation

To get started with KitCat, simply install it globally using npm:

```bash
npm install -g kitcat
```
